\# Video Stream App



A movie browsing web application built using HTML, CSS, and JavaScript. Users can browse movies, search by title, add movies to their favourites and cart, and access login and registration pages.



\## Features



\- Browse movies with posters, titles, years, categories, and ratings.

\- Search movies by title.

\- Add movies to favourites and remove them.

\- Add movies to the cart and remove them.

\- Login and registration pages.

\- Automatic image carousel.



\## Technologies Used



\- HTML5

\- CSS3

\- JavaScript

\- Fetch API

\- JSON Server

\- Local Storage



\## Project Structure



\- `index.html` — Main movie listing page

\- `index.css` — Website styling

\- `index.js` — Movie listing, search, carousel, and interactions

\- `cart.html` and `cart.js` — Cart page and functionality

\- `favourite.html` and `favourite.js` — Favourites page and functionality

\- `Authentication/` — Login and registration pages



\## Running Locally



1\. Clone or download this repository.

2\. Open the project folder in VS Code.

3\. Run `npm install`.

4\. Configure and start JSON Server with the local movie database.

5\. Open the application using a local development server.



\*\*Note:\*\* The application currently uses a local API at `http://localhost:3000`. The backend must be configured separately for the application to work fully on another computer or on a deployed website.
